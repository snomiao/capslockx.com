Lab

Working notes from designing CapsLockX. Rough by intent — these are the arguments, not the manual.

  • The .clx binding language · interactive
    One line per binding: a gesture pattern, =>, an action. Both halves already existed in the project — this draft format only puts them next to each other. With a playground.
  • What a plugin actually is
    A plugin is something a binding can call. Argues for exposing effects rather than domains, so the core never has to know what a plugin is for — and notes that otoji has been one all along, informally.
  • A script store, not another executable
    Why shipping each small feature as its own .exe stopped scaling, what the pieces already in the tree give for free, and the one thing genuinely missing.
  • Porting #DPW#
    AutoHotkey types a password when you type #DPW#. Porting it is two questions wearing one coat: generating a password is trivial and safe, retrieving a stored one is neither. This separates them and ships only the first.
  • Key probe · interactive
    Records what the foreground application really receives, so it can be diffed against what the WH_KEYBOARD_LL hook logged for the same keystrokes. The gap between the two lists is exactly what CapsLockX suppressed or injected.
  • The quiet window · interactive
    Keyboard tests need the keyboard, and the author was using it. A hands-off protocol: the page opens, you press Run test and let go, and the test drives a machine nobody is typing on.
  • F1–F12, rethought in the notation
    Five ways to put function keys on the number row, compared in the gesture language rather than in prose. Where the design landed, and what it cost.
  • The CapsLock+Space chord
    A 40-case edge-case audit of the shipped design, its blast radius across the existing hotkey layers, and the notation itself. Defines (a+b)[ c ].
  • Gesture parser · interactive
    Type on the page and watch real key edges fold into the notation, live. Doubles as a keyboard rollover test.
  • The Alt variant · superseded
    The first attempt, kept for the record. Rejected because it costs Alt+Space and would let Alt+F4 close your window by accident.

These pages describe work in progress and contain claims that were later withdrawn — corrections are marked in place rather than deleted, since the wrong turns are usually the interesting part.
